# Placey
A modern, full-stack property rental platform inspired by Airbnb. Built with Vue 3, Tailwind CSS, and ASP.NET Core, Placey enables hosts to manage listings and guests to discover and book accommodations.

## Functions
- [ ] Property listings with photos, location, amenities
- [ ] Search & filter (dates, location, price range, guests)
- [ ] Availability calendar (conflict checking on backend)
- [ ] Host dashboard (manage listings, see bookings, earnings)
- [ ] Guest dashboard (upcoming/past trips, reviews)
- [ ] Reviews & ratings system

Optional:
- [ ] Messaging between host and guest
- [ ] Stripe payments


## Technologies
- Vue, Tailwind 
- ASP.NET Core
